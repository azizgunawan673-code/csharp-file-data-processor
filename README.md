# 🛠️ C# File & Data Automation Tool

A lightweight C# console application designed to handle file I/O operations, structured text parsing, and automated data reporting. Built as a portfolio project for C# freelancing opportunities.

---

## ✨ Key Features
- 📄 **Automated File Generation**: Creates sample data files automatically if not present.
- ⚡ **Batch Data Parsing**: Reads and iterates through records smoothly (`System.IO`).
- 📊 **Structured Console Reporting**: Formatted output tracking total records processed.

---

## 🛠️ Tech Stack
- **Language**: C# (.NET 8.0)
- **IDE**: Visual Studio Code
- **Platform**: Cross-platform (Windows / Linux / macOS)
